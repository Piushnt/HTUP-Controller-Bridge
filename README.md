# HTUP-Controller-Bridge
HTUP Controller Bridge (Ulrich PadLink) transforme toute manette USB, DirectInput ou Ucom en contrôleur sans fil pour mobile. Conçu pour le jeu mobile et le Esport, il convertit et transmet les signaux via Wi-Fi UDP ultra-basse latence ou Bluetooth HID. Il intègre la normalisation des axes, l'anti-drift et un tableau de bord moderne.
